Nushell assistant

A shell session that runs entirely in this tab. Ask for something in plain words and the fine-tuned model writes the Nushell command, which then runs in the session. Or type Nushell yourself. The model runs on WebGPU; Nushell runs as WebAssembly over an in-memory project.
